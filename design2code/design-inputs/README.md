# 设计输入目录

每个页面需求都建议单独建立一个目录：

```txt
design-inputs/<page>/
├── intent.md
└── design_ir.json
```

MVP 阶段以 `intent.md` 作为主要输入。后续可以把 Figma 截图、Figma MCP 输出等作为额外意图来源补进来。

`intent.md` 示例：

```md
# 页面意图

页面名称：通知公告场景管理
页面类型：列表管理页
业务对象：公告展示场景

主要功能：
- 查询
- 新增
- 编辑
- 删除
- 启停

字段：
- 场景名称
- 应用场景编号
- 所属级别
- 级别编号
- 布局类型
- 是否展示
- 更新时间
```
