# 审批文书详情视觉风格

## 1. 定位

审批文书详情视觉风格用于申请单、审批单、台账式详情等页面。它允许比普通后台列表更强的表格边框和文书感，但属于特定业务场景，不应扩散到普通 CRUD 页面。

```txt
bigboss-wedo/src/module/main/ema/assetMaintenance/retirement/table.vue
```

共享样式：

```txt
bigboss-wedo/src/css/applyTable.css
```

## 3. 视觉规则

- 页面背景为白色。
- 正文容器可作为 PDF 导出区域。
- 顶部申请标题居中，字号约 `19px`，字重 `600`。
- 区块标题使用左侧 4px 主题竖线。
- 区块标题字号约 `16px`，字重 `600`。
- 表单字段可使用表格布局和较重边框。
- 字段字号偏紧凑，常见 `13px`。
- 编辑态表格顶部可使用 `2px solid var(--line-color)`。
- 右侧状态块固定，完成态为绿色，进行态为主题色。
- 右侧锚点导航可使用白底、圆角和轻阴影。

## 4. 生成页面时的注意事项

- 只有审批申请、文书详情、台账式详情才使用该风格。
- 普通列表页仍应使用 Element UI 浅边线和 `baseTableV2`。
- 重边框、表格化表单是业务文书特例。
- 主题强调必须使用 `var(--theme-color)` / `var(--line-color)`。
- 如果页面需要导出 PDF，应先规划稳定导出容器。
