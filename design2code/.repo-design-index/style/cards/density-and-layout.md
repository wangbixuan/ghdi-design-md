# 信息密度和布局节奏

## 1. 定位

GHDI 是工作型企业后台，布局应偏紧凑、稳定、可扫描，而不是展示型、营销型或强装饰型。

## 2. 来源

- `seed/design.md`
- `seed/page-designs/*.md`
- `.repo-design-index/patterns/PAGE_PATTERNS.md`

## 3. 规则

- 页面首屏应优先呈现可操作内容。
- 列表页保持搜索、工具栏、表格、分页的稳定秩序。
- 配置页保持设置区、编辑区、附件区、预览区的清晰层级。
- Dashboard 只在统计概览场景使用。
- 审批文书类重边框是业务特例，不扩散到普通列表。

## 4. 生成页面时的注意事项

- 不要做大 hero。
- 不要把后台页面做成卡片瀑布流。
- 不要为“好看”牺牲批量操作、查询、分页、状态展示。
- 保持按钮和信息组之间的距离稳定，不做随意偏移。
