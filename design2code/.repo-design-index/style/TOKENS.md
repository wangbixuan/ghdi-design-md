# Style Tokens

These tokens describe the intended design memory. The current codebase primarily consumes CSS variables such as `--theme-color` and `--line-color`; this file names the stable concepts for planning and review.

| Token | Value | Notes |
|---|---|---|
| `--theme-color` | runtime configured | Primary theme color from menu/system configuration |
| `--line-color` | runtime configured | Emphasis line/accent color |
| `--app-text-title` | `#303133` | Element UI primary text |
| `--app-text-body` | `#606266` | Element UI regular text |
| `--app-text-secondary` | `#909399` | Element UI secondary text |
| `--app-border` | `#DCDFE6` | Element UI base border |
| `--app-border-light` | `#E4E7ED` | Light border |
| `--app-border-lighter` | `#EBEEF5` | Lighter table/divider border |
| `--app-bg-page` | `#F5F7FA` | Page background |
| `--app-bg-card` | `#FFFFFF` | Card/control background |
| `--app-radius-control` | `4px` | Element UI base radius |
| `--app-font-body` | `14px` | Body text |
| `--app-font-meta` | `12px` | Meta/status text |
