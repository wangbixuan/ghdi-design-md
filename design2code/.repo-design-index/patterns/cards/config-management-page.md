# config-management-page

## 1. 定位

配置详情 / 内容编辑类页面，用于编辑业务对象、通知公告、规则模板、发布配置和富文本内容。

## 2. 适用需求

- 通知 / 公告编辑
- 模板选择
- 发布规则绑定
- 富文本编辑
- 附件 / 封面上传
- 预览
- 规则变更提醒

## 3. 推荐结构

```txt
页面标题区
配置表单区（两列）
主编辑区（富文本 / 大表单）
附件扩展区
预览 / 关联对象抽屉
底部保存操作
```

## 4. 推荐组件

- `EditorVue`
- `File`
- `SearchSelectUser`
- Element UI Form / Dialog / Drawer

## 5. 数据流和事件流

- 表单模型保存业务对象。
- 富文本通过 `EditorVue` 事件回写。
- 附件通过 `File v-model` 回写。
- 预览可能依赖后端保存后的实体 ID。

## 6. 详细说明

详细 Design MD：`../config-management-page.md`

## 7. 生成页面时的注意事项

- 不要把配置页压成普通一列表单。
- 预览、规则详情、规则创建优先抽屉 / 弹窗，不离开当前编辑上下文。
- 保存、预览、规则切换之间的业务约束要写清楚。
