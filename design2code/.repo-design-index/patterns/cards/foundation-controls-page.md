# foundation-controls-page

Element UI 基础控件状态参考页，不是普通业务页面模式。

## 2. 适用需求

- 控件规范展示
- 主题联动验证
- 设计系统说明页面

## 3. 推荐组件

- Element UI Button / Input / Select / Table / Dialog / Tag / Pagination

## 4. 详细说明

详细 Design MD：`../foundation-controls-page.md`

## 5. 生成页面时的注意事项

- 不要把它当业务页面模板。
- 它主要用于校验控件状态和主题变量。
