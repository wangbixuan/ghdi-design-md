# theme-engine-page

## 1. 定位

系统主题管理和预览页面，用于配置系统默认主题、菜单主题色和主题变量效果。

## 2. 适用需求

- 系统主题配置
- 菜单颜色配置
- 主题预览
- 设计系统调试

## 3. 推荐组件

- Element UI Form
- `iconPicker`
- `SearchSelectUser`
- 上传组件按业务需要使用

## 4. 详细说明

详细 Design MD：`../theme-engine-page.md`

## 5. 生成页面时的注意事项

- 这是系统配置类特例，不应用于普通业务页面。
- 主题配置要尊重 `--theme-color` / `--line-color` 链路。
