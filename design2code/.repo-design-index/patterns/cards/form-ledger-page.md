# form-ledger-page

## 1. 定位

审批型、文书型、台账型表单页面，信息密度高，强调业务字段、流程尾部和操作导航。

## 2. 适用需求

- 审批表单
- 台账式详情
- 工单 / 申请 / 流程相关业务对象
- 需要保留文书感的密集字段页面

## 3. 推荐结构

```txt
标题 / 单据信息
密集字段区
附件 / 说明区
审批 / 流程信息
右侧操作或导航
```

## 4. 推荐组件

- `File`
- `EditorVue`
- `WorkFlowDetail`
- `SearchSelectUser`

## 5. 详细说明

详细 Design MD：`../form-ledger-page.md`

## 6. 生成页面时的注意事项

- 这是业务文书特例，较重边框和密集字段不要扩散到普通列表。
- 流程信息和主业务表单要区分层级。
